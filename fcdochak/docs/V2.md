# FC도착 v2 — 설계와 작업 나누기

**v2 의 한 줄:** 비교해 주는 오픈마켓 → **셀러의 쿠팡 FC 도착 원가를 확정하고 책임지는 운영 플랫폼**으로 옮겨 가는 첫 판.
근거는 2026-09-25 사이트 전수 분석(구조적 모순 8 · 방안 A~F · P0/P1/P2). 9구간 표준화는 그대로 쓴다.

## 지키는 선

- 가지: `fcdochak-v2` 가 v2 의 줄기. 작업 가지 `v2/<꾸러미>` → `fcdochak-v2` 로 합친다. **`main`·`fcdochak`(운영)은 건드리지 않는다.**
- 미리보기: https://fcdochak-v2.vercel.app (Vercel 로그인 필요) · **임시 DB(PGlite)** — Supabase 연결값은 운영에만 있다. v2 의 새 표가 운영 DB 에 들어가지 않는다.
- 미리보기 띠: 환경변수 `PREVIEW_BANNER`(v2 가지에만 `v2`)가 있으면 모든 화면 맨 위에 「v2 미리보기 — 운영 아님」.
- **계약을 떠안거나 돈을 받는 것은 자리만 만들고 스위치는 꺼 둔다.** 확정가·회송 보장·후불·공동 혼적은 화면·계산·기록까지만. 켜는 값은 `fcd.settings` 의 `v2.*` 스위치, 기본 꺼짐.
  근거: 확정가는 국제물류주선업 등록(법인 자본금 3억 원 이상·보증보험)이, 보장은 보험사 제휴가, 후불은 금융사·결제대행 제휴가 전제다. 사람이 정할 일이다.
- 돈 계산은 `src/lib/money` 순수 함수 + `tests/` 시험. 거래 기록은 새 판(`supersedes_id`)으로 쌓고 UPDATE 권한을 주지 않는다.
- 밖으로 나가는 것은 `sendOutbound` · `OUTBOUND_ENABLED` 꺼짐 그대로. 초대 링크는 화면에 보여 주고 복사하게 한다.
- 새 표는 RLS + 정책 + 데모면 `DEMO_TABLES`·걷어내기 시험.

## 꾸러미와 손댈 자리

번호는 겹치지 않게 미리 나눈다. 여러 꾸러미가 같이 만지는 자리(`src/lib/terms.ts`, `seed/demo/index.ts`, `src/lib/server/demo-status.ts`, `src/lib/db/migrations.generated.ts`, `src/components/shell/nav.tsx`, `seed/reference`)는 **덧붙이기만** 하고 기존 줄을 고치지 않는다 — 합칠 때 충돌을 줄인다. 시험은 꾸러미마다 새 파일(`tests/v2-<꾸러미>.test.ts`, `e2e/v2-<꾸러미>.spec.ts`).

| 꾸러미 | 무엇 | 마이그레이션 |
|---|---|---|
| **p0** 신뢰 버그 | 기준 화물 하나로(계산기 기본값 = `STANDARD_CARGO`, 「이 조건 기준」 표시) · 「상위 N곳」 개수 따라 · 미래 날짜 후기 막기 · 데모 메뉴 버튼 · 홈 H1 접근성 이름 · 9구간 막대 대체 글 → 요약 문장 + 표 · 「확정 합계」와 「참고치 포함 합계」 분리 · 정렬 기준 토글(가격순/추천순)과 현재 기준 표시 · 특수관계 업체 1위 경고(순위 계산에서 기본 제외 선택지) · v2 미리보기 띠 | 없음 |
| **check** 청구서 점검 | 공개 `/check` — 견적서·청구서를 엑셀/붙여넣기/직접 입력으로 올리면 9구간으로 가르고 구간 시세(중간값·상위 25%)와 비교, 추가비용·빠진 구간·과한 구간을 짚는다. 로그인 없이 결과, 로그인하면 보관. 홈 첫 행동을 「내 견적서·청구서 점검받기」로 | `0006_invoice_checks.sql` |
| **tools** 가입 전 가치 | 공개 `/tools/pnl` 판매손익 계산기(도착원가·관부가세 추정·쿠팡 수수료 → 개당 마진·손익분기) · 구간 화면에 구간별 9구간 중간값·합계 공개(업체별 가격·견적 요청만 가입 뒤) · 화물 특성 토글이 결과와 연결(취급 불가 업체 제외 + 추가비용 경고) | 없음(설정은 참조 시드에 덧붙임) |
| **trust** 점수·후기 | 점수를 항목별로 · 표본이 기준 미만이면 「표본 부족」 · 청구편차 평균 + 상위 10% 최악 · 회송·분실 선적도 평가 · 업체 공개 답변 | `0007_reviews_v2.sql` |
| **assure** 확정가·보장 자리 | 확정가 견적(구간 원가 변동폭 → 초과 위험 → 프리미엄, 순수 함수) · 회송 보장 견적(업체 회송률 → 보장료) · 후불 신청 · 공동 혼적 참여 의사 — 모두 스위치 꺼짐이면 「시범 준비 중 · 관심 등록」만 받는다. 어드민 설정 화면에 스위치·요율 | `0008_assure.sql` |
| **workspace** 셀러 공간 | 선적 타임라인 한눈 · 서류함(인보이스·패킹리스트·쿠팡 바코드 PDF 분류) · 청구 승인/이의 · 거래처 초대(내 포워더를 링크로 초대 → 가입하면 내 거래처로 연결, 발송은 꺼짐) | `0009_workspace.sql` |
| **metrics** 이벤트·지표·목적지 | 견적 → 선택 → 선적 → 입고 → 청구 이벤트 기록 · 어드민 새 지표(월간 활성 셀러 · 관리 선적 수 · 초대 업체 비율 · 재선적률 · 견적 대비 청구 차이 · 회송률 · 선적당 매출) · 목적지 넓히기(쿠팡 FC 외 국내 3PL·다른 쇼핑몰 창고를 참조표에 두고 계산기·견적에서 고를 수 있게) | `0010_events.sql`, `0011_destinations.sql` |
