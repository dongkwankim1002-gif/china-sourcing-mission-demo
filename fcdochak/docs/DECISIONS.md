# 판단 기록 — 한 줄에 하나

- 작업 가지는 세션이 지정한 `claude/fcdochak-phase-1-0n4xlc` 하나로 하고, 단계는 커밋으로 나눴다(`fcdochak-<단계>` 가지 여러 개 대신). PR 은 `fcdochak` 으로.
- `fcdochak` 기준 가지는 `main` 에서 새로 떴다. `main` 과 저장소 뿌리 파일은 건드리지 않았다(뿌리에 도구 설정이 없어 예외가 필요 없었다).
- 표는 `public` 이 아니라 `fcd` 스키마에 둔다 — Supabase PostgREST 에 기본 노출되지 않게.
- Supabase 의 `anon`/`authenticated` 대신 자체 역할 `fcd_user`·`fcd_public` 로 `set local role` 해서 RLS 를 받는다. 앱은 서버에서만 DB 에 붙는다.
- 로그인 확인은 Supabase Auth(있으면)·로컬 scrypt(없으면), 세션은 자체 서명 쿠키(`fcd_session`, HS256). 브라우저에 Supabase 키를 두지 않는다.
- `fcd.profiles.id` 는 `auth.users` 를 FK 로 참조하지 않는다 — 로컬 PGlite 와 같은 스키마로 돌리고, 데모 걷어내기를 한 SQL 로 끝내려고.
- 환경변수가 없으면 PGlite 로 끝까지 돈다(시험·미리보기·로컬). 두 드라이버의 값 모양(date·timestamptz·int8)을 같게 맞췄다.
- 마이그레이션은 SQL 파일을 빌드 때 TS 로 묶어(`migrations.generated.ts`) 서버리스에서도 파일 없이 올린다. 시험이 둘이 같은지 본다.
- 거래 기록 표(요금표·응찰·청구·설정·관세율·등급)는 UPDATE 권한 자체가 없다. 정정은 `supersedes_id` 로 새 판을 쌓는다. 상태 칸만 바뀌는 표(요청·예외·광고 등)는 따로 둔다.
- 삭제 요청 처리 = 업체 상태를 `deleted` 로 바꾸기(공개 면에서 사라짐). 실제로 지우는 SQL 은 만들지 않았다.
- 참조표(거점·항구·FC·구간·화물 성격)는 코드가 원본이라 `db:migrate` 때 upsert 한다. 설정·관세율은 키가 없을 때만 첫 판을 넣고, 운영자가 쌓은 판은 덮지 않는다.
- 돈 계산은 `src/lib/money` 의 순수 함수만. BigInt 로 자릿수를 고정하고 반올림은 사사오입, 세금은 원 단위 버림.
- 성사 수수료 기준 = 물류비 합계 − 관세사 보수, 관세·부가세 제외(관세사법 제3조 제2·3항). 시험으로 고정.
- 관세·부가세는 「참고 추정」으로만 보이고 목록통관은 다루지 않는다.
- 업체가 맡지 않는 구간은 플랫폼 참고치(설정 `reference_lines`)로 채워 합계를 보이되, 점선 무늬로 구분하고 확정 합계에서는 뺀다.
- 비교 목록은 운송(freight) 구간을 포함한 요금표만 올린다 — 운송이 없는 요금표는 같은 조건 비교가 안 된다.
- 비로그인 계산기는 「공개 가격」으로 표시한 요금표만 쓰고, 금액 대신 구간 비중(천분율)만 돌려준다.
- 추천 점수 = 정시 30 · 청구 편차 25 · FC 회송 25 · 가격 확정도 20. 실측이 없으면 중립 0.5. 광고·특수관계는 점수에 넣지 않는다.
- 광고는 한 구간·기간에 한 자리만(서버에서 겹침 검사), 목록 맨 위에 「광고」 표시.
- 「FC 입고 준비 인증」 기준(60건·3.5%)은 설정 표에서 읽는다. 쿠팡 상표는 쓰지 않는다.
- 공개 정보 업체(미등록)는 이름·지역·업종·출처만. 가격·소개·사진·개인 연락처를 싣지 않는다.
- 물류사는 경쟁사의 비공개 요금표를 볼 수 없다(`fcd.i_am_shipper()` 로 화주에게만 비교용 공개) — 시험 있음.
- 화주 이름은 예약 전까지 물류사에 보이지 않는다(orgs RLS).
- 9구간 막대의 색은 순서(한 색상 명도 단계, 밝음→짙음)만 싣고, 확정도는 무늬(예상 빗금·추가비용 호박 테·참고치 점선)로 싣는다 — 색각 이상에서도 읽히게. 팔레트는 validate_palette 로 밝은·어두운·남색 위 세 벌 검사.
- 차트는 한 계열·한 축만. 두 축 차트를 쓰지 않았다.
- 큰 숫자·브랜드·공개 제목에는 Black Han Sans 를 쓴다(요청 사항). 본문·표의 숫자는 Pretendard 고정폭 숫자.
- 글꼴은 저장소에 묶었다(Pretendard 하위집합·Black Han Sans, OFL). 외부 CDN 을 부르지 않는다.
- frontend-design 스킬은 이 환경에 없어, DESIGN.md 를 먼저 쓰고 캡처 검토를 두 번 돌리는 방식으로 대신했다.
- next-intl 은 물류사 콘솔에만(ko/zh). 쿠키 `fcd_locale` → 사용자 설정 → ko 순.
- 밖으로 나가는 것은 `sendOutbound` 한 곳을 지나고 기본 꺼짐. 앱 안 알림(DB)은 늘 쌓인다. Supabase Storage 올리기는 우리 저장소라 스위치 밖에 둔다.
- 서류 파일은 비공개 버킷 + 짧은 서명 주소로만 내려준다. Supabase 가 없으면 기록만 남기고 파일은 받지 않는다.
- 공개 계산 API 는 IP 당 분당 90회로 막는다(메모리 기준 — 서버리스 인스턴스마다 따로 셈).
- 데모 조직 규모는 「최근 40건·진행 60건」에 더해 90일 추이를 그릴 지난 기록을 함께 넣었다(점수·편차가 실측에서 나오게).
- 데모 운영자도 데모 운영 조직(is_demo) 아래에 둬 걷어내기 한 번에 사라지게 했다.
- `demo:purge` 는 SQL 파일만 만든다. Supabase `auth.users` 정리도 같은 파일에 id 목록으로 넣는다.
- `DEMO_MODE` 는 실행 때 읽지만, 공개 쪽 미리 그린 쪽 때문에 바꾸면 다시 배포하라고 문서에 적었다.

- 글꼴은 unicode-range 조각(Pretendard 92·Black Han Sans 120) 대신 KS X 1001 한글 2,350자+라틴·기호 한 파일씩으로 줄였다 — 조각마다 배치 비용(파일당 약 18ms)이 붙어 모바일 Lighthouse 성능이 60~70대였다. 드문 음절·한자는 시스템 글꼴로 넘어간다(`scripts/fonts/build.sh`).
- 글꼴(640KB)은 첫 화면 경로에서 뺐다: 처음 온 기기는 그 쪽을 시스템 글꼴로 끝까지 그리고 한가할 때 파일만 캐시에 받아 두며, 다음 쪽 로드부터 머리에 글꼴 CSS 를 파싱 중에 써 넣어(캐시에서) 처음부터 붙인다(`layout.tsx` fontScript — optional 은 첫 그리기 뒤엔 영영 안 바뀌어 쓰지 않음). 로드 뒤 바꿔 끼우면 CLS 0.2, 미리 받기(preload)는 느린 4G 에서 LCP 6초라 둘 다 뺐다.
- 로그인 쪽은 검색에 열어 둔다(공개 쪽). robots 의 `/partner` 가 공개 `/partners` 까지 막던 것을 `/partner$`·`/partner/` 로 좁혔다. 청록(--ok) 밝은 값은 칩 배경 위 대비 4.5 를 넘기려 #0C7166 으로 한 단계 짙게.

- postgres.js 는 jsonb 자리에 넘긴 JSON 글자를 한 번 더 JSON 으로 감싼다 — 2026-09-25 첫 Supabase 시드(설정·응찰·청구 금액 등)가 글자로 감싸여 저장됐다. 드라이버가 쓰기는 다시 감싸지 않게, 읽기는 한 겹 벗기게 고쳐 저장된 자료는 건드리지 않았다(지우거나 덮는 SQL 을 돌리지 않는 규칙). SQL 쪽에서 jsonb 안을 읽는 곳은 없다.
- 배열(text[]·int[])도 드라이버가 직접 푼다 — 풀러 뒤에서 postgres.js 가 배열 형식을 못 알아내는 경우 대비.

- v2 tools — 공개/가입 후 선: 구간별 9구간 중간값·합계·최저·업체 이름·판매손익 계산기는 공개, 업체별 9구간 가격 비교와 견적 요청은 가입 후. 구간 목록·구간 화면에 같은 안내(`OpenGate`)를 두고 「가격은 가입 후」를 「업체별 가격과 견적 요청은 가입 후」로 고쳤다. 홈 계산기의 공개 가격 업체 총액(요금표에 「공개 가격」 표시한 곳)은 그대로다.
- v2 tools — 홈 계산기 응답(`buildQuoteResponse`)에 뺀 업체 이름·사유(`excludedList`)를 덧붙였다 — 전에는 「뺀 곳 N」 숫자만 있었다. 공개 머리 메뉴에 「판매손익 계산」, 바닥글·홈 도구 띠·홈 계산기·구간 화면에서 계산기로 조건을 실어 보낸다(`?lane=` 또는 `?hub·port·mode·화물·traits`).
